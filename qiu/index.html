数据口径

  • 数据来自各平台公开的热搜 / 热榜接口，经本站 Cloudflare Worker 归一化后缓存 10 分钟，所以「实时」指的是分钟级，不是秒级。
  • 热度值沿用平台自己的口径（播放量 / 热度 / 指数），不同平台之间不可直接比较，所以不做跨平台总排名。
  • 「疑似求资源」是按关键词命中的粗筛（资源、全集、下载、教程、破解、汉化…），只是提示，不是平台官方标签。
  • 点条目默认跳到该平台的搜索页（视频类条目会直接跳到视频页）。链接都是平台原站，本站不存内容。
  • 每个平台配了多个数据源按顺序回退（官方接口 → 60s API → rebang.today）。走到后面的兜底源时，条目可能是该平台的「热门内容」而不是「搜索热词」，标题也可能被上游截断；每张卡片右下角的「来源」会写出这次用的是哪一路。
  • 某个平台暂时取不到时会显示上一次成功的快照并标注「数据偏旧」，不会整页空白。
