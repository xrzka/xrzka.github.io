数据口径

  • 日 / 周 / 月 / 年榜：把每天抓到的 star 数存成快照，榜值 = 当前 star − N 天前快照的 star，只统计正增量。
  • 新星榜：近 90 天创建、star 最高的应用；总榜：star 总量。
  • 候选池来自 GitHub Search API，按 topic × star 区间 分片枚举；打上 android / ios / flutter / desktop-app / electron / tauri 等 topic 的应用优先收录，也可以在 data/seeds.txt 里手工补仓库。
  • 仓库分类（手机 / 电脑）由 topic、语言与简介关键词打分得出，可能有个别误判。
  • 名字或简介里带 library / framework / sdk / awesome / tutorial 之类的会被标成「库/框架」「清单/教程」，默认不上桌（否则 flutter/flutter 这类框架会霸榜），勾选后可显示。
  • 快照每天 UTC 定时更新一次，页面是静态快照，不是实时数据。
